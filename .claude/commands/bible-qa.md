# 回答聖經問題技巧

此 skill 整合所有知識庫的讀取方式，讓你能根據聖經問題，從正確的來源擷取資料並給出有根據的答案。

---

## 知識庫總覽

| 知識庫 | 路徑 | 用途 |
|--------|------|------|
| 經文與註解（已生成） | `verses/{書名縮寫}/{書名縮寫}_{章:02d}_{節:02d}.md` | 快速讀取單節經文及恢復本腳注 |
| 生命讀經（已生成） | `life-study/{NN}_{書名}_{MMM}.md` | 讀取李常受弟兄的生命讀經信息 |
| 聖經資料庫（原始） | `db/bible.sqlite` | 動態查詢，用於知識庫不足時 |

**優先順序：先讀已生成的 `.md` 檔，避免不必要的 SQL 查詢。**

---

## 一、讀取經文與腳注

### 方法 A：直接讀 `verses/` 檔（優先）

```
verses/{書名縮寫}/{書名縮寫}_{章:02d}_{節:02d}.md
```

範例：
- 創世記 1:1 → `verses/創/創_01_01.md`
- 約翰福音 3:16 → `verses/約/約_03_16.md`
- 詩篇 119:105 → `verses/詩/詩_119_105.md`

檔案結構：
```markdown
# 創 1:1

> ¹起初²神³創造⁴諸天與地，

---

## 註解

**註1**
…

**註2**
…
```

若需要連續多節，批量讀取對應的多個 `.md` 檔。

### 方法 B：SQLite 動態查詢（備用）

當需要整章、範圍查詢，或 `verses/` 尚未生成時使用。詳見 `/bible-verse` skill。

---

## 二、讀取生命讀經信息

### 方法 A：直接讀 `life-study/` 檔（優先）

```
life-study/{NN}_{書名}_{MMM}.md
```

- `NN`：書卷編號（01–66）
- `MMM`：篇次（001–起）

範例：
- 創世記第1篇 → `life-study/01_創世記_001.md`
- 馬太福音第5篇 → `life-study/40_馬太福音_005.md`

**查詢某書卷總篇數：** 讀 `life-study/manifest.json`，key 為書卷編號（數字字串）。

```json
{ "1": { "name": "創世記", "total": 120 }, … }
```

### 方法 B：全文搜尋（跨篇查詢）

當問題涉及特定主題或關鍵字，使用 Grep 工具搜尋：

```
pattern: "關鍵字"
path: life-study/
glob: *.md
```

## 四、問題類型與對應策略

### 類型 1：「某節經文是什麼意思？」

1. 讀取 `verses/{縮寫}/{縮寫}_{章:02d}_{節:02d}.md` 取得原文與腳注
2. 在 `life-study/` 中 Grep 該節引用（如 `約三16`）找相關信息
3. 綜合腳注與生命讀經回答

### 類型 2：「某主題在聖經中怎麼說？」

1. Grep `life-study/` 搜尋主題關鍵字
2. 找出相關篇次後讀取完整內容
3. 同時讀取對應經節的 `verses/` 確認原文

### 類型 3：「某書卷第N篇講什麼？」

1. 查 `manifest.json` 確認該書卷編號
2. 直接讀 `life-study/{NN}_{書名}_{NNN:03d}.md`

### 類型 4：「某章的所有經節」

批量讀取 `verses/{縮寫}/` 下符合章次的所有檔案，或用 SQLite 整章查詢。

---

## 五、注意事項

- **詩篇 segment_code=0**：詩篇各章有章首標題（`segment_code=0`），不是經節，通常跳過
- **詩歌體**：詩篇、箴言等 `unit_code > 0` 的分行，合併時不加換行，直接串接
- **腳注上標**：`verses/` 檔中已含上標（¹²³…），直接引用即可，無需重新計算
- **簡稱查詢**：若不確定書卷簡稱，查本文件對照表或 SQLite `volume_all_big5_01`
