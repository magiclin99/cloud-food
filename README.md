## 神永遠的經綸

根據以弗所書的生命讀經（第75篇）及提摩太前書的腳注，以下是簡要說明：

---

### 一、「經綸」的字義

**「經綸」**（希臘文：*oikonomia*，奧依克諾米亞）原意是**家庭管理、家庭行政、行政的安排**，引申為「分賜」——即有計畫地將某物分發給家中成員。

**神的經綸**就是**神計畫要將祂自己分賜到祂所揀選的人裡面**（提前 1:4 腳注）。

---

### 二、經綸的核心：基督同召會

神的永遠經綸，簡言之，就是**「基督同召會」**（弗75篇）：

- **神的奧祕**是**基督**——基督是神的具體表現和彰顯（西 2:2）
- **基督的奧祕**是**召會**——召會是基督的身體，彰顯基督（弗 3:4）
- 所以，「基督同召會」就是神意願、喜悅、定旨、奧祕的核心答案

---

### 三、神的永遠心意（弗 1:10）

神的目標是：**在時期滿足時，將萬有在基督裡歸一於一個元首之下**（弗 1:10）。

這經綸從**已過的永遠**（創立世界以前）就定了，要延伸到**將來的永遠**（新天新地）。

---

### 四、完成經綸的步驟

神藉著以下步驟完成祂的經綸（弗 75篇）：

| 步驟 | 說明 |
|------|------|
| **揀選** | 創立世界以前，在基督裡揀選了我們（弗 1:4） |
| **豫定** | 豫先標出我們得兒子的名分（弗 1:5） |
| **救贖** | 藉基督的血救贖我們（弗 1:7） |
| **得救** | 團體的救恩，產生召會（弗 2:5, 8） |
| **聖化** | 在性情上被改變、變化（弗 5章） |
| **長大** | 長到元首基督裡面（弗 4:15） |
| **建造** | 被建造成基督的身體（弗 2:22, 4:16） |

---

### 五、一句話總結

> **神永遠的經綸，就是神計畫要將祂自己分賜到祂所揀選的人裡面，使他們成為基督的身體（召會），作神的彰顯，直到萬有在基督裡歸一，達到神永遠的定旨。**

這就是為何提摩太前書 1:4 說，保羅的職事中心是「神在信仰裡的經綸」——凡與此岔出的教訓，都是「不同的教訓」。
